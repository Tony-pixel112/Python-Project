# Python Practice Projects

Small Python programs I wrote while learning to code. Each script is a standalone exercise covering core concepts like loops, functions, file handling, and user input.

## Projects

- **Calculator**: basic arithmetic calculator
- **Banking Program**: deposit, withdraw, and check balance
- **Quiz Game**: multiple-choice quiz
- **Rock Paper Scissors**: play against the computer
- **Guessing Game**: guess the random number
- **Dice Roller**: simulates rolling a dice
- **Folder Organizer**: sorts files into folders (console and GUI versions)
- **Encryption**: simple text encryption
- **Count Down Timer**: timer that counts down from a set time

## Run a program

```
python Calculator.py
```

Requires Python 3.
